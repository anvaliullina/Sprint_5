
# Sprint 5 — Stellar Burgers

## Описание проекта

Проект автоматизированного UI-тестирования веб-приложения Stellar Burgers.

Сайт: https://stellarburgers.education-services.ru/

В проекте реализовано 13 автотестов для проверки основных пользовательских сценариев.

## Технологии

- Python
- Selenium WebDriver
- Pytest
- Google Chrome

## Проверяемая функциональность

### Регистрация пользователя
- Успешная регистрация с уникальным email и корректным паролем
- Проверка ошибки при вводе некорректного пароля

### Авторизация
- Вход через кнопку «Войти в аккаунт» на главной странице
- Вход через кнопку «Личный кабинет»
- Вход через ссылку на странице регистрации
- Вход через ссылку на странице восстановления пароля

### Личный кабинет
- Переход в личный кабинет после авторизации
- Переход из личного кабинета в конструктор через кнопку «Конструктор»
- Переход в конструктор через логотип Stellar Burgers
- Выход из аккаунта

### Конструктор бургеров
- Переключение на вкладку «Булки»
- Переключение на вкладку «Соусы»
- Переключение на вкладку «Начинки»

## Структура проекта

- `tests/test_registration.py` — тесты регистрации
- `tests/test_login.py` — тесты авторизации
- `tests/test_personal_account.py` — тесты личного кабинета и выхода
- `tests/test_constructor.py` — тесты конструктора бургеров
- `tests/conftest.py` — фикстура для запуска и закрытия браузера
- `locators.py` — локаторы элементов интерфейса
- `generators.py` — генерация уникальных email и паролей
- `.gitignore` — исключения для Git
- `README.md` — описание проекта

## Установка зависимостей

Для установки необходимых библиотек выполните команду:

```bash
python -m pip install selenium pytest
```

## Запуск автотестов

Для запуска всех тестов выполните команду из корневой папки проекта:

```bash
python -m pytest tests/ -v
```

Для запуска отдельного набора тестов:

```bash
python -m pytest tests/test_registration.py -v
```
